A la izquierda tienes los conceptos gramaticales.

Verbos Grupo 1 (Godan)

• う, つ, る → って (買う → 買って)
• む, ぶ, ぬ → んで (飲む → 飲んで)
• く → いて (書く → 書いて) Excepción: 行く → 行って
• ぐ → いで (泳ぐ → 泳いで)
• す → して (話す → 話して)

Grupo 2 (Ichidan)

• Se quita る y se añade て (食べる → 食べて)

Grupo 3 (Irregulares)

• する → して
• 来る → 来て (くる → きて)

Regla General (Todos los grupos)

Para la forma て negativa, se usa la forma ない, añadiendo で. Significa "sin hacer X" o petición negativa.
• 食べない → 食べないで (Sin comer)
• 行かない → 行かないで (Sin ir / No te vayas)
• する → しないで
• 来る → 来ないで (くる → こないで)

Variante: なくて

Forma ない: quitar い + くて. Se usa para causa o motivo.
• 分からない → 分からなくて (分からなくて困った: Como no entendía, me vi en apuros)
• 食べない → 食べなくて

Formas Corteses Avanzadas

• お願いいたします (humilde de "por favor")
• ～ております (humilde de "estar haciendo")
• ～でございます (muy formal de "ser")

Regla General (Todos los grupos)

Se toma la forma ます y se cambia por ません.
• 飲みます → 飲みません
• 食べます → 食べません
• します → しません
• 来ます → 来ません (きます → きません)

Grupo 1 (Godan)

Grupo 2

Grupo 3

する → しました

Regla General (Todos los grupos)

Se toma la forma ません y se añade でした.
• 飲みません → 飲みませんでした
• 食べません → 食べませんでした
• しません → しませんでした
• 来ません → 来ませんでした (きません → きませんでした)

Grupo 1 (Godan)

Excepción: Terminados en う → わない (買う → 買わない)

Grupo 2

Grupo 1 (Godan)

Se forma igual que la Forma て, cambiando て/で por た/だ.
• う, つ, る → った
• む, ぶ, ぬ → んだ
• く → いた
• ぐ → いだ
• す → した

Grupo 2

Quitar る + た (食べる → 食べた)

Grupo 3

する → した
来る → 来た (くる → きた)

Regla General (Todos los grupos)

Se toma la forma ない en pasado (quitando la い y añadiendo かった).
• 飲まない → 飲まなかった
• 食べない → 食べなかった
• しない → しなかった
• 来ない → 来なかった (こない → こなかった)

Adjetivos en い

• Presente: 高い
• Pasado: Quitar い + かった (高かった)
• Forma て: Quitar い + くて (高くて)
Excepción: いい → よかった, よくて

Adjetivos en な

• Presente: 静かだ / 静かです
• Pasado: 静かだった
• Forma て: 静かで

Adjetivos en い

• Presente: Quitar い + くない (高くない)
• Pasado: Quitar い + くなかった (高くなかった)
Excepción: いい → よくない, よくなかった

Adjetivos en な

• Presente: 静かじゃない (o ではない)
• Pasado: 静かじゃなかった (o ではなかった)

Transitivos (他動詞)

Llevan objeto directo (partícula を). Alguien hace algo a algo.
Ejemplo: ドアを開ける (Abro la puerta).

Intransitivos (自動詞)

No llevan objeto directo, el sujeto sufre la acción por sí mismo.
Ejemplo: ドアが開く (La puerta se abre).
